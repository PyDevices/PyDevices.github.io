omnipython-lvgl — LVGL v9 for MicroPython, CircuitPython and CPython.

omnipython-lvgl LVGL v9 for Python: one binding generator turns LVGL's C headers into a MicroPython module, a CircuitPython module and a CPython wheel, so a program imports lvgl the same way on a desktop and on both kinds of board.
