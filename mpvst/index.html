mpvst

MPVST — audio effects and instruments as a VST3 plug-in.

mpvst Programmable VST3 instruments and effects: every audiocomponents instrument and effect as a named plug-in, each instance running its Python in a sidecar process. Installers for Windows and Linux; nothing has to be built.

Install

Download it; nothing has to be built

Get the archive for your platform from the latest release; each comes with a .sha256 to check it against.

# Windows: installs for you alone, so there is no administrator prompt
MPVST-0.3.0-windows-x86_64-setup.exe

# Linux: copies the bundle to ~/.vst3
tar xf MPVST-0.3.0-linux-x86_64.tar.gz
./install.sh               # in the unpacked folder

Then rescan plug-ins in your DAW, and make it a real rescan, not a restart: hosts cache what they found last time. The installers are not code signed, so Windows SmartScreen warns the first time. REAPER is the only DAW tested.

Try this first

Find an instrument by its own name

Search your FX browser for TR-808, Minimoog or Tape Delay and drop it on a track. Every instrument and effect in audiocomponents shows up under its own name and category. Its editor has a patch selector, a bypass switch, a status light and a slider per macro. The two MPVST Script Host entries run a script you point them at, and stay silent until you do.
