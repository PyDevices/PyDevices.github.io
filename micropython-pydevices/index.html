micropython-pydevices The PyDevices patch queue for MicroPython, kept like a distribution keeps one: an ordered, provenance-tracked patch series over the pinned upstream release (v1.29.0), with presets, boards and variants that build PyDevices modules into firmware with upstream's own make.

Install

Prepare a MicroPython checkout once

Clone this repository beside a MicroPython clone and the PyDevices modules you want. One script checks out the pinned release (v1.29.0) and applies the whole patch series as a single local commit.

git clone https://github.com/PyDevices/micropython-pydevices
git clone https://github.com/micropython/micropython
micropython-pydevices/tools/prepare-micropython.sh

Try this first

Build with a preset, using upstream's own make 
cd micropython/ports/unix
make VARIANT_DIR=../../../micropython-pydevices/variants/unix/pydevices \
     FROZEN_MANIFEST=../../../micropython-pydevices/manifests/lvgl.py

A preset is a short list of the sibling repositories a build carries: lvgl.py is displayif with lvgl-micropython, audio.py is audiodsp with audioif, usb.py is usbif. The esp32 boards take BOARD_DIR= the same way. The presets lists them all.
