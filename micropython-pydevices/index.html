micropython-pydevices The PyDevices patch queue for MicroPython, kept like a distribution keeps one: an ordered, provenance-tracked patch series over the pinned upstream release (v1.29.0), with presets, boards and variants that build PyDevices modules into firmware with upstream's own make.

Install

One line, on Linux or WSL 
curl -fsSL https://pydevices.github.io/install.sh | sh

It clones this repository into ~/micropython-pydevices (or updates the clone already there), checks the tools every build needs, and tells you what's missing for each port. Add a build after -- to do both at once: curl -fsSL https://pydevices.github.io/install.sh | sh -s -- --port unix --variant pydevices --modules all

Build

One command; the first run fetches what it needs 
cd ~/micropython-pydevices
./build_mp.py          # asks for port, board, variant, flash size and modules
./build_mp.py --port unix --variant pydevices --modules all
./build_mp.py --port esp32 --board ESP32_GENERIC_S3 --variant SPIRAM_OCT --flash 8MB --modules all
./build_mp.py --port rp2 --board RPI_PICO2 --modules displayif,lvgl-micropython

build_mp.py fetches the pinned MicroPython release, applies the patch series, fetches the PyDevices modules you name at their pinned commits and each port's toolchain, and builds into builds/. An esp32 build grows its app partition to fit, and a Pico build sizes its filesystem around the firmware.
