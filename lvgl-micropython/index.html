lvgl-micropython — MicroPython C usermod for LVGL v9.

lvgl-micropython Native MicroPython C module integrating LVGL v9 graphics engine with displayif bus drivers across ESP32, RP2040, and i.MX RT targets.

Build Firmware Instructions

Compile as a MicroPython User C Module 
# Clone lvgl-micropython:
git clone https://github.com/PyDevices/lvgl-micropython.git

# Build MicroPython firmware with LVGL enabled:
cd micropython/ports/esp32
make BOARD=ESP32_GENERIC_S3 USER_C_MODULES=../../../lvgl-micropython
