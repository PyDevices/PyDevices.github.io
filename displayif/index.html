Where it went

Same code, same history, one repository fewer

displayif now lives in micropython-pydevices, the repository that builds MicroPython with PyDevices' C modules compiled in. It was never released on its own: it reached you in firmware built by micropython-pydevices, so that is where it is built, tested and changed now. The old repository is archived and kept as a record; open issues and pull requests against micropython-pydevices.

Build it in

Name it in the build, as before 
git clone https://github.com/PyDevices/micropython-pydevices
cd micropython-pydevices
./build_mp.py --port unix --modules displayif

Your code doesn’t change: spibus, i80bus, mipidsi, dotclockframebuffer and the other bus modules import as before. --modules all builds it with everything else.
