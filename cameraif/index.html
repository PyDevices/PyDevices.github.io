cameraif

cameraif — a MIPI-CSI camera as a MicroPython object.

cameraif Point the board at something and read the frame. The sensor is found by probing rather than named in code, so a different camera is a build-time option away, not a rewrite. Hardware JPEG, zero-copy frames and hardware scaling straight into a display's scanout buffer, with every rate in its README measured on the board it names.

Install

A user C module for the ESP32-P4

Nothing is released yet; you build it into MicroPython 1.29. The esp32 port needs two small patches first, then one line in the manifest your P4 build already uses.

/path/to/cameraif/apply_patches.sh --apply /path/to/micropython

# in the manifest your P4 build already uses
include("/path/to/cameraif/manifest.py")

The README covers your own FROZEN_MANIFEST and other ports, where the module builds with its bodies stubbed.

Try this first

Take a still 
import cameraif

cam = cameraif.Camera(sda=7, scl=8, reset=21)
print(cam.sensor())                 # ('OV5647', 22087)
print(cam.size())                   # (800, 800, 1280000)

open("still.jpg", "wb").write(cam.capture_jpeg(85))
cam.deinit()

The pins are the ones on the board cameraif was proved on; use your board's. The sensor is found by probing, so you never name it in code.
