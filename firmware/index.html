OmniPython MP and CP, for the boards we have run

Pick your board, then press Install in Chrome or Edge, or follow the esptool steps in any browser. Everything here is built by public CI from one pinned commit and attested, so you can check a file came from it.

Copy your files off the board first, secrets.py above all. A build can move the filesystem, and flashing across a layout change leaves it empty. Coming from another firmware (MicroPython to CircuitPython, or back), erase the flash first.
