Firmware downloads

OmniPython for your board

Find your board below, download its image and flash it with mcuctl or esptool. The firmware is MicroPython-compatible or CircuitPython-compatible, with the OmniPython libraries built in. Every file is on the GitHub release, built there by public CI and attested.

OmniPython firmware 0.8.1 (2026-11-26) carries OmniPython 0.8.1, audiodsp 0.6.17, pygraphics 0.2.1, omnipython-lvgl 9.6.2. Built 2026-11-26 by this run.

The interpreters underneath are previews (MicroPython is v1.30.0-preview, not a tagged release; CircuitPython is 11.0.0-alpha.3, a pre-release), so the release is marked as a pre-release, and mcuctl takes it with --preview.

Copy your files off the board first, secrets.py above all. A board whose filesystem sits somewhere else in this build starts with an empty one. Compare the Filesystem column with yours, and when you come from another firmware (MicroPython to CircuitPython, or back), erase the flash first.

Flash with mcuctl

mcuctl fetches a board's image from the release, checks its sha256 and writes it to an ESP32 over serial. The build id is the board's id in the table.

pip install mcuctl
mcuctl firmware download --source omnipython --board mp-s3-octal --preview
mcuctl firmware flash --port esp32 --artifact <the file it printed> --device <serial port>

The Arduino GIGA's images are written in its bootloader (machine.bootloader() at the REPL, or double-tap RESET), the Wi-Fi firmware first. The Wi-Fi image only changes when its driver does, so after the first time you can leave it out. Write the ROMFS image with every update: it holds the firmware's own Python modules. The flash guide has the steps.

Some QT Py ESP32-S3 boards have no PSRAM and need the no-PSRAM image. Run esptool chip-id: a board with PSRAM has an Embedded PSRAM entry on its Features line.

Check a download came from our CI:

gh attestation verify <file> --repo PyDevices/omnipython-builds

Each file's sha256, size and offset, and the pins the set was built from, are in firmware.json.
