airwindows

airwindows — 528 Airwindows plug-ins as audio nodes.

airwindows Chris Johnson's Airwindows effects, reverbs, dynamics, filters, saturation and tape among them, ported to audiodsp's audio graph, the same on MicroPython-compatible firmware and CPython. Install omnipython-airwindows from PyPI, or build audioairwindows into your firmware beside audiodsp.

Install

PyPI for CPython, a firmware build for boards 
# CPython 3.11 or later: a prebuilt wheel, with audiodsp beside it
pip install omnipython-airwindows

The plug-ins are C, so on a board they are built into the firmware beside audiodsp, as user C modules. Install has the commands, and which plug-ins a board build carries.

Try this first

A burst of noise through Galactic's reverb 
from array import array
import audiocore, audioairwindows

RATE = 48000
noise, x = array("h"), 1
for _ in range(RATE // 50):
    x = (x * 1103515245 + 12345) & 0x7fffffff
    noise.append((x >> 16) % 20001 - 10000)

verb = audioairwindows.Galactic(sample_rate=RATE, channel_count=1, replace=0.3)
verb.play(audiocore.RawSample(noise, sample_rate=RATE, channel_count=1))
for row in range(12):
    loudest = 0
    for _ in range(48):
        block = array("h", bytes(audiocore.get_buffer(verb)[1]))
        loudest = max(loudest, max(abs(v) for v in block))
    print("%.2f s  %5d" % (row * 48 * 256 / RATE, loudest))

It prints the loudest sample of each quarter second or so, the same on CPython and MicroPython: the reverb tail, dying away over three seconds. On a board, hand verb to audio_out.play() instead of pulling it yourself. To put something worth processing in front of it, add audioinstruments.
