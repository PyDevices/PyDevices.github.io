Where it went

Same code, same history, one repository fewer

audioif now lives in micropython-pydevices, the repository that builds MicroPython with PyDevices' C modules compiled in. It was never released on its own: it reached you in firmware built by micropython-pydevices, so that is where it is built, tested and changed now. The old repository is archived and kept as a record; open issues and pull requests against micropython-pydevices.

Build it in

Name it in the build, as before 
git clone https://github.com/PyDevices/micropython-pydevices
cd micropython-pydevices
./build_mp.py --port unix --modules audiodsp,audioif

Your code doesn’t change: audiobusio and _audioif import as before. The portable half of the audio pump, and every DSP node, is audiodsp.
