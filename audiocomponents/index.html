audiocomponents — 55 classic instruments and 45 effects, in pure Python, on audiodsp.

audiocomponents The instrument and effect libraries for audiodsp: audioinstruments (55 modelled classics, from the TR-808 to the DX7) and audioeffects (45 effect classes and racks), pure Python on MicroPython and CPython. Ships as pydevices-audioinstruments and pydevices-audioeffects, each a standalone distribution and a MIP package.

Install

TestPyPI for CPython, the MIP index for boards 
# CPython: both packages from TestPyPI; audiodsp comes along from PyPI
pip install -i https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ \
  pydevices-audioinstruments pydevices-audioeffects
# MicroPython, on a firmware that has audiodsp in it
import mip
mip.install("audioinstruments", index="https://PyDevices.github.io/mip")
mip.install("audioeffects", index="https://PyDevices.github.io/mip")

Both are pure Python. On a board they need a firmware built with audiodsp, whose nodes they are made of.

Try this first

A Minimoog through a tape delay 
import audioinstruments, audioeffects

audioeffects.configure(48000)
minimoog = audioinstruments.create("minimoog", sample_rate=48000)
chain = audioeffects.create("TapeDelay", minimoog.output, sample_rate=48000)

minimoog.note_on(60)
# chain.output goes to a mixer voice, audiodev, or the next effect

audioinstruments.ALL and audioeffects.ALL list every name create() takes. An effect's output is the same object for the life of the effect, so you can wire it once and every later knob move is heard. To play the same library in a DAW, install MPVST.
