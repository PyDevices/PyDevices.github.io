One omip line puts them all on a Wi-Fi board; pip puts them on a desktop.

Put them on a board

One line at a Wi-Fi board's REPL 
import omip
omip.install("github:PyDevices/apps/apps")
omip.install("github:PyDevices/apps/apps/home/main.py", target="/")

The board needs OmniPython firmware with LVGL, its board config and Wi-Fi. The first line puts every app on it, each with what it needs; the second starts Home when the board starts. Reset the board, and Home comes up with a tile for each app. To put on one app at a time, name its folder, as in omip.install("github:PyDevices/apps/apps/clock"). Install an app has the board config line, CircuitPython's extra step, updating, and how to start in one app with Home behind it.

Home and Watch

Where the apps start from

Home is the home screen: a tile for each installed app, on a tab per category. On a round or small screen, Home's main.py starts Watch instead: a watch face with the date, the battery and today's steps, then a wheel of the same apps. Swipe sideways for another face, and tap for the wheel. Every app installs on any board, and one that can't run there says why when you start it.

On a computer

pip, from GitHub 
# every app, as the package apps, with the libraries they share
pip install "omnipython-apps @ git+https://github.com/PyDevices/apps#subdirectory=apps"

The libraries alone (appkit, controlkit, touchkit and the rest) are one package for writing apps of your own: omnipython-applibs from PyPI, or applibs from lib.omnipython.org.
