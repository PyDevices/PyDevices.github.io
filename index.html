PyDevices Engine

One display & hardware contract. 5 Python runtimes.

PyDevices is a cross-platform Python hardware driver engine, board contract specification, and display stack. Built around pydevices as its flagship core, it provides standardized board configurations (board_config.py), eager UI hardware initialization, lazy peripheral management (boarddev), and unified display abstractions (displaydev).

Write your display and hardware logic once and run it unchanged across 5 target environments: MicroPython, CircuitPython, CPython desktops, PyScript web PWAs, and Android APKs.

pygraphics

Extended 2D FrameBuffer graphics engine with exposed read-only attributes, dirty Area tracking, 24-bit RGB888 for NeoPixel/DotStar arrays, custom fonts, and optional C acceleration.
