OmniPython

One Python program, on boards, desktops, browsers and phones.

OmniPython is a set of Python libraries and C modules that run unchanged on MicroPython, CircuitPython and CPython. Give each board or host a small board_config, and the same program drives its display, input and audio.

Install it with pip on a desktop or omip on a board: the install page has the line for each. Or try it first, with nothing installed: the watch on this page is Python running in your browser, and every app in the gallery runs the same way.

Core

The board contract: a small board_config per board, and display, touch, audio and event code that runs the same on all three Pythons.

Graphics

2D drawing, text and bitmaps: native C where it is built in, pure Python everywhere else.

LVGL
